# Juan Stream - Plataforma de Streaming Multimedia

Proyecto practico de Programacion Web (4to Semestre - Ingenieria en Sistemas, UIDE).

Aplicacion Full Stack construida con FastAPI, SQLModel (SQLite) y almacenamiento multimedia en Amazon S3 (bucket media3.3), con frontend Mobile First en HTML5, CSS Grid/Flexbox y JavaScript sin innerHTML.

## Ejecucion

1. Crear entorno virtual: python3 -m venv venv && source venv/bin/activate
2. Instalar dependencias: pip install -r requirements.txt
3. Iniciar API: uvicorn main:app --reload
4. Abrir index.html con Live Server.
